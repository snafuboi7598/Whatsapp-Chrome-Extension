# WhatsApp Chrome Extension 🚀



A powerful Chrome extension that enhances WhatsApp Web with AI-powered features using OpenAI's GPT API. Designed for automation, convenience, and productivity, this extension integrates natural language capabilities into your WhatsApp experience.

---

## ✨ Features

- 🔍 **AI Chat Assistance**: Auto-generate replies and summaries using OpenAI API.
- 🧠 **Message Understanding**: Understand tone, intent, or classify messages.
- ⚙️ **Automation Capabilities**: Optionally like, forward, or tag messages based on content.
- 💬 **Personalized Suggestions**: Tailor responses to customer or contact context.
- 🧪 **Debugging/Logging Panel**: Developer-focused logging for message flows.
- 🛡️ **Secure Input Mode**: Keeps personal API keys in `.env` (excluded from repo).
